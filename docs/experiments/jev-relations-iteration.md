# Jev 局部关系实验：调用前设计

本轮继续只跑 Jev，不推远程、不提升默认。维持模型 jev-1.13.0、六轮、10 秒超时、零重试和原始概率门槛。旧 v2 holdout 已公开并用来分析失败，本轮明确将其部分案例转为开发材料，不再称独立验证。

补充局部语法事实：只解析可确定的不可变字符串绑定、字符串拼接及字面量数组 join，列出加载参数的表达式、解析名称及代码位置；未知参数保留未知，不执行源文件，也不把事实提示直接转换成答案。模型仍收到完整代码，支持度仍由原有规则计算。包清单中仅对严格识别的完整 `node -e/--eval` 命令拆出内联 JS，保留原命令；复杂 shell、插值和无法解析的代码不伪装成已解析。

先运行有反例的 12 个开发案例和旧 40 个回归，再冻结生产修改，打开新的 20 例 v3 验证材料。四类各五例、包含中英文，标签按提供的代码关系预先确定；不要求已部署执行，直接引入即算使用。确认新材料没有像 h05 那样依赖未提供消费者的标注假设。首次调用后不修改生产和标签来追求得分；若失败，原样保留并说明下一步。

预先独立目标维持：无错误确定结论、无错误删除建议、宏平均 F1 >=0.95、待审查率 <=30%（标准 25%）、六例换序稳定。延迟、API 耗时和本地处理单独报告，与前轮只作历史比较，不把不同时段的请求波动归因于某一因素。没有真实 LLM 对照。

# Jev 第二轮：使用判定改善，未使用判定仍保守

新版修正了选项重叠和低置信度调查过早结束的问题。在同一批 40 个已知合成案例上，Jev 不再全部返回待审查：120 次正式审查中，55 次给出确定答案，全部与预先标签一致。未使用案例仍全部待审查，因此没有达到全部保留标准，默认继续使用 LLM。

## 设计变化

1. 最终判定改为三个独立 Noul 问题：运行使用、工具链使用、未使用证据是否充分。运行和工具链可以同时成立，程序映射回原有类别，不再让“确实使用”和其工具链子类竞争一个单选答案。
2. 当前事实分别接受这些判断，证据放在对应的结构化问题中。声明、扫描器结论、文档与历史记忆不充当当前使用证明；模型状态排除声明和扫描器意见，保留声明/引用标志用于程序规则与现有融合。
3. 存在未完成调查时不提供结束选项。单一剩余动作由程序直接执行。多个调查都合理、Choice 置信度不足时，程序继续第一个允许且未完成的动作，保留模型建议、概率和实际动作。API 错误仍只降级当前候选，不转 LLM。
4. 肯定判断和支持记录继续要求二元置信度至少 0.8，即 Noul 概率至少 0.9。未使用判定还要求运行和工具链概率均不超过 0.1，且无相反使用证据；没有通过降低删除门槛获得更好结果。
5. 保存独立原始概率，并明确标记程序组合的五类融合权重。组合权重不是原生类别概率，融合分数也不是已校准的正确率。

问题拆分和结构化证据遵循 [官方 API](https://docs.typesafe.ai/api) 与 [模型局限中的建议](https://docs.typesafe.ai/model-jaggedness/jev-1.13)。一次请求并行评估这些问题，没有追加理由生成或 LLM 调用。

完整审查 p50 相比本轮 LLM 降低 83.42%；只统计确定答案时，p50 降低 82.88%。确定答案准确率与耗时是各自已作答子集的指标：Jev 的确定答案只覆盖运行和工具链使用，不包括未使用类别，不能据此宣称所有任务准确率为 100% 或相同子集上的纯模型速度优势。

错误删除建议按预先标签计算，没有实际删除。重复测量次数不等于不同依赖数。初版原始记录保持不变，见 [第一轮结论](../jev-2026-10-11/README.md)。两轮改变了多处设计，而且 API 结果会变化，不能把改善全部归因于某一个因素。

## 各类别与剩余待审查原因

| 预先标签 | 正式次数 | 新版最终类别正确 | 返回待审查 |
| --- | ---: | ---: | ---: |
| 工具链使用 | 30 | 28 | 2 |
| 运行使用 | 30 | 27 | 3 |
| 高置信未使用 | 30 | 0 | 30 |
| 证据不足、需待审查 | 30 | 30 | 30 |

65 次待审查中，61 次是最终独立判断置信度不足，4 次是支持记录未达到证据门槛。没有因低置信度调查顺序提前中止；两次调查排序由程序接管并继续完成。30 次本来就缺少证据的案例均正确待审查；另外 35 次未给出对应确定类别。

例如 `unused-1` 第一轮的运行概率为 0.04，工具链概率为 0.05，但“未使用证据充分”的概率只有 0.70，支持记录最高为 0.75，未达到 0.90。模型倾向未使用，并没有充分确信已有记录能支持该结论。这个问题涉及证据覆盖与门槛校准，不能仅凭这批合成材料断言全部是模型或 Harness 的缺陷。

## 门槛前的候选类别，仅作诊断

将保存的五类组合权重取最高项，120 次候选类别中有 116 次与标签一致，宏平均 F1 为 0.9666。此项不是最终审查准确率，也不是另一套可直接采用的结果：它没有通过证据、置信度和业务检查，使用的也是程序组合权重，而非原生单选输出。

四次候选错误中，`unused-10` 第三轮倾向待审查；`ambiguous-7` 三轮都倾向未使用，尽管消费者代码未提供。后者的未使用概率分别只有 0.54、0.52、0.51，最终均被保留为待审查。如果只选概率最大的类别而取消门槛，这三次会产生不当的未使用结论。这也是没有为了降低待审查率直接删除检查的原因。

门槛前的表现支持继续研究 Jev 的价值，但阈值是否过高必须在独立标注材料上校准；同一批已知案例不适合作为调参后的独立验收集。

## 顺序与语言检查

正式材料包含英文 81 次、中文 39 次。Jev 英文给出 37 次确定答案、44 次待审查；中文给出 18 次确定答案、21 次待审查。

另外选择六个案例，正常顺序和反转动作选项/问题顺序各跑完整审查，六例的最终类别均一致。其中两例都给出了正确的确定类别，四例两次都是待审查。该检查没有隔离随机波动和顺序影响，也没有证明所有案例稳定；两个相同的待审查结果不能代表稳定提供了确定答案。

## 验收与下一步判断

正式数据完整、零错误删除建议、F1 不低于 LLM、p50 至少减半、p95 不恶化及六例顺序检查均通过。**待审查率增加不超过 5 个百分点这一项未通过**：Jev 为 54.17%，LLM 为 20%，增加 34.17 个百分点。没有更改标准使本轮通过。

本轮已能看到新版在确认使用上的价值；自动确认未使用的覆盖率还没有改善。后续应独立验证证据覆盖是否足以支持全项目非使用结论，并使用新的标注案例校准门槛。默认仍为 LLM，保留本地实验分支，不推送远程。

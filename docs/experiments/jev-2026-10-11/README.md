# Jev 对照结果：保留实验，不启用默认

完整运行了 40 个预先标注的合成案例，每种提供方每例预热一次、测量三次，共 240 次正式审查。Jev 的耗时明显下降，但全部结果为待审查，未达到“质量不下降”的标准。

“错误删除建议”按预先标签统计推荐删除但目标标签不是 `high-confidence-unused` 的次数，没有实际删除文件或依赖。同一案例测量三次，因此次数不等于不同依赖数。宏平均 F1 对语料中四种目标类别计算；本批没有 ghost 目标类别。API 失败返回待审查也是已完成的审查结果，不属于运行器缺失行。

Jev 的速度优势包含调查阶段提前退回待审查的情况，不能理解为相同质量的确定答案快了 80%。现有 LLM 在这套语料上的 F1 也较低且存在错误删除建议，比较结果不能证明任一提供方适合直接自动删除。

## 降级与稳定性

Jev 的 120 次审查中，119 次因低置信度降级，1 次调用失败。由最终分布是否存在可区分：65 次低置信度发生在最终判定，54 次发生在调查选择。调用失败样本为 `ambiguous-4` 第二轮，耗时约 10 秒，与超时相符；报告未保存错误响应体，不能据此进一步确认服务端原因。

一个具体样本是 `tooling-lint` 第一轮：`likely-tooling-usage` 概率 0.58，`confirmed-used` 概率 0.31，置信度 0.47，低于最终判定门槛 0.8。选项定义中“可执行配置证明使用”和“工具链使用”可能重叠，是后续应单独验证的候选原因，尚未证明是全部失败的根因。实验没有为通过验收而降低门槛或改写标签。

中英文正式审查均覆盖：英文每种提供方 81 次，中文各 39 次；Jev 两组均 100% 待审查。额外的中英文固定工具链材料各做一次正序和逆序 Choice 请求，四次均选择 tooling。这只证明这两个简短材料的选项选择一致，没有覆盖整条审查流程或所有案例的选项换序稳定性。
